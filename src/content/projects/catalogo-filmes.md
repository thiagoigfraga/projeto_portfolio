Sistema de catálogo de filmes desenvolvido com Angular e TypeScript. O projeto conta com:

- ✨ Interface responsiva com Material Design
- 🔍 Sistema de busca e filtros avançados
- 🎬 Integração com API de filmes para dados atualizados
- 🚀 Deploy em produção com Firebase Hosting
- 📱 Design mobile-first

Uma aplicação que demonstra conhecimentos sólidos em desenvolvimento front-end moderno, consumo de APIs e boas práticas de UX/UI.
