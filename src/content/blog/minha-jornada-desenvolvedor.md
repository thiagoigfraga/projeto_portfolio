# Minha Jornada como Desenvolvedor

Começar no mundo do desenvolvimento web pode parecer intimidador, mas cada linha de código escrita é um passo em direção ao crescimento profissional e pessoal.

## Os Primeiros Passos

Minha jornada começou durante a faculdade de Ciência da Computação, onde tive o primeiro contato com programação. Inicialmente, as linguagens básicas como C e Java me deram uma base sólida sobre lógica de programação e estruturas de dados.

## Descobrindo o Front-end

Foi quando descobri o desenvolvimento front-end que tudo mudou. A possibilidade de criar interfaces visuais e interativas me fascinou. HTML, CSS e JavaScript se tornaram meus companheiros diários.

### React.js: O Divisor de Águas

Aprender React.js foi um momento transformador. A biblioteca me permitiu criar aplicações mais robustas e organizadas, e desde então se tornou minha ferramenta principal para desenvolvimento front-end.

## Tecnologias que Fazem a Diferença

Durante essa jornada, algumas tecnologias se destacaram:

- **TypeScript**: Trouxe mais segurança e produtividade ao meu código
- **Astro**: Framework moderno que uso neste próprio portfólio
- **CSS3**: Para criar interfaces responsivas e atrativas

## O Futuro

Continuo aprendendo e me desenvolvendo constantemente. Cada projeto é uma oportunidade de crescer e aplicar novas tecnologias. Estou sempre em busca de desafios que me permitam evoluir como desenvolvedor.

A jornada está apenas começando, e estou ansioso para ver onde ela me levará!
